# S520J 参赛演示视频脚本

> 适用版本：v1.2.3（`dist/S520J-v1.2.3-debug.apk`）
> 成片建议：主版 3 分 00 秒；另出 60 秒精简版应对限时要求

## 一、成片规格

| 项目 | 设定 |
| --- | --- |
| 画幅 | 竖屏 9:16，导出 1080×1920 |
| 录制 | 手机录屏 1080p / 60fps，关闭指针位置与触摸圆点 |
| 风格 | 安静、克制、暖调；以字幕叙事为主，口播为辅 |
| 色彩 | 与 App 一致：暖白 `#F8F6EE`、鼠尾草绿 `#7D9676` |
| 音乐 | 极简钢琴，音量压到 -22dB，不抢字幕 |
| 节奏 | 每个功能 8–18 秒，不做长时间静止画面 |

## 二、录制前准备

1. 两台 Android 手机安装同一 APK（v1.2.3），分别登录 `12345678` 与 `123456789`
2. 两台都开启通知权限，关闭勿扰与静音，媒体音量调到 60%
3. 关闭自动亮度、护眼模式、系统手势提示条；使用同一壁纸避免穿帮
4. 确认数据已就绪：照片 5 条、心愿 3 条、情书 2 封、带图记录 6 条
5. 把手机时间显示统一，避免画中画里时间不一致
6. 点菜额度提前确认（每日 100 次，保底 20 次），录制前不要反复试跑耗尽
7. 每个场景单独录一条原始素材，命名 `scene01_raw.mp4`，不做边录边剪

## 三、分镜脚本（主版 3:00）

### Scene 1｜开场（0:00–0:10）

- **画面**：纯暖白背景，无 UI。标题手写体淡入，停留 2 秒后淡出。
- **字幕**：
  - `有些话，只想说给一个人听。`
  - `有些日子，只想和一个人过。`
- **音效**：单个钢琴音，轻。
- **注意**：不要放 App 界面，先立情绪。

### Scene 2｜问题（0:10–0:25）

- **画面**：三张纯文字卡片快切，每张 3 秒；文字块在第 4 秒聚合成 App 图标与名称。
- **字幕**：
  - `聊天记录会滚走`
  - `照片会散在相册里`
  - `"今天吃什么"，每天都要重新商量`
- **转场**：文字聚合 → 缩放进入首页（0.4 秒）

### Scene 3｜心动：一端记录，另一端看到（0:25–0:55）

- **主画面**：A 机（1080 全屏）
- **操作序列**：
  1. 首页顶部问候卡停留 1.5 秒
  2. 点「今日挑战」→ 勾选今日一项 → 返回，进度条变化
  3. 「心愿」卡片点「答应」→ 状态即时切换 + 轻提示
  4. 点「碰碰你」→ 选「抱一下」→ 发送成功反馈
- **画中画**：B 机录屏缩到右下角（占屏 1/3），在 0:45 左右弹出横幅通知
- **字幕**：`一端记录，另一端 20 秒内看到。`
- **重点**：状态变化要真实可见，不加速、不跳剪；提示条出现后停留 1 秒。

### Scene 4｜拾光：两个相册变成一个（0:55–1:20）

- **操作序列**：
  1. 切到「拾光」→ 照片墙按「旅行」筛选，列表刷新
  2. 点顶部「共同照片」统计卡 → 进入总览子页
  3. 点任意一张 → 全屏大图 → 左右滑动两张 → 返回
  4. 返回照片墙 → 右下角「+」→ 选择「一起做的菜」→ 保存，卡片出现在顶部
- **字幕**：`两个人拍的照片，最后会变成同一个相册。`
- **重点**：大图翻页必须完整展示一次，证明不是静态图。

### Scene 5｜今天吃啥：一次点击凑一桌（1:20–1:55，核心镜头）

- **操作序列**：
  1. 进入点菜页，停留 1 秒展示四个分组
  2. 荤 2、素 2、汤 1、主食 1（依次点选，展示份数变化）
  3. 口味/分类选「川菜」
  4. 点「开始」→ 结果页出一桌菜（完整停留 3 秒）
  5. 点「换一桌」→ 结果变化
  6. 展开本次来源与剩余额度，展示降级说明
- **字幕**（分两条）：
  - `荤素汤主食，一次凑齐一桌。`
  - `实时菜谱、云端菜品池、本机快照、内置 90 道——四级降级，断网也能出结果。`
- **重点**：这是作品最强的差异化镜头，剪辑上给足时长，不叠加其他 UI。

### Scene 6｜默契：一封情书（1:55–2:18）

- **操作序列**：
  1. 切到「默契」→ 横滑经过 2 个模块（显示横向列表有内容）
  2. 停在「一封情书」→ 点「查看全部」
  3. 在「写给 TA / 来自 TA」之间切换一次，列表方向翻转
  4. 打开其中一封 → 阅读 2 秒 → 返回
  5. 滑到「相处之道」，展示「双方已确认」状态
- **字幕**：`有些承诺，需要两个人都点下确认。`

### Scene 7｜我们：边界与双向确认（2:18–2:38）

- **操作序列**：
  1. 切到「我们」→ 情侣资料卡
  2. 进入「共同空间」→ 展示成员、绑定状态
  3. 进入「通知中心」→ 列表有几条未读
  4. 进入「隐私与权限」→ 展示「仅自己 / 两个人」两档
  5. 进入「数据管理」→ 回收站与 ZIP 导出入口
- **可选增强**：B 机点「解除绑定」→ A 机出现确认弹窗，停留 2 秒（体现双向确认）
- **字幕**：`私密内容只有两档可见：仅自己，就我们俩。`

### Scene 8｜技术与结尾（2:38–3:00）

- **画面**：
  1. 架构图 3 秒（Compose → ViewModel → Repository → 云函数 → PostgreSQL）
  2. 终端执行测试，滚动到 `302 tests passed`，停留 2 秒
  3. 转「关于」页，静止停留 3 秒（页面含「致一周年的我们」）
- **字幕**：
  - `Kotlin · Compose · CloudBase · PostgreSQL`
  - `302 个单元测试 · 8 套规格文档 · 34 个阶段安装包`
- **结尾卡**（黑底暖白字，3 秒）：
  - `S520J`
  - `只属于两个人的共同生活记录`
  - `github.com/Logsti/Android-APP-S520J`

## 四、口播稿（可选，约 45 秒）

> 如果比赛允许旁白，建议只在这几处开口，其余交给字幕；语速偏慢，不要念稿感。

- 开场：`这个 App 只装在两个人的手机里。`
- 心动：`她随手记下的一点小事，我这边不用刷新就能看到。`
- 点菜：`最难的不是写菜谱接口，是每天都要回答"今天吃什么"。`
- 结尾：`它没有上架，也不打算上架——因为它只服务于一段关系。`

## 五、字幕规范

- 字体：思源黑体 Medium，字号 36–40，白字 + 20% 黑色阴影
- 位置：画面下方 15%，不遮挡操作区与按钮
- 每条不超过 18 字，停留不少于 1.5 秒
- 不使用花字、不使用弹跳动画

## 六、后期要点

1. 转场统一 0.3 秒淡入淡出，最多用一次缩放转场（Scene 2 → 3）
2. 关键点击处做 1.2–1.5 倍局部放大，配 2px 圆角高亮框，时长 1.2 秒
3. 双机同步镜头用画中画，右下角、占屏 1/3、加 1px 细边框
4. 隐私处理：真实头像、昵称、手机号一律模糊；测试内容已脱敏
5. 不加速真实加载过程；若等待超过 3 秒，用 0.5 秒叠化跳过，并在字幕注明"实际约 X 秒"
6. 导出：H.264 / 1080p / 8Mbps / AAC 192kbps，文件名 `S520J_参赛演示_3min.mp4`

## 八、预演与风险

| 风险 | 应对 |
| --- | --- |
| B 机通知未弹出 | 录制前两台各发一次测试动作，确认通知权限与电池优化已关闭 |
| 同步延迟超过 20 秒 | 切换到前台后触发一次同步；仍失败则重录该镜头 |
| 点菜额度耗尽 | 提前一天不要试跑；保底链路仍有结果，但来源说明会变化 |
| 关键操作被系统弹窗打断 | 录制前关闭系统更新提示、清理通知栏 |
| 画中画时间不同步 | 两台机同时开始录屏，后期对齐首次点击的帧 |
