## 功能

- [x] 心动页顺序正确：今日挑战、快速记录、心愿待实现、碰碰你、共同日历、最近的美好，顶部保留问候与相伴天数
- [x] 共同日历显示完整月份、日期可选、今日高亮、事项标记、前后月切换、返回今天
- [x] 碰碰你 DIY 可增可删，发送有反馈

- [x] 我们页可进入账号与绑定流程
- [x] 所有列表具备空状态与新增入口

## 账号与空间

- [x] 一键注册：账号 ID 由用户手动设置（8–20 位字母数字、trim 后 uppercase 存储、唯一性校验），昵称 + 自设恢复码（8–32 位字母数字、区分大小写）
- [x] 恢复码仅存加盐哈希，APP 内无查看明文入口
- [x] 登录 = 账号 ID + 恢复码；换机可恢复
- [x] 绑定状态七态齐全，双方确认后为已绑定
- [x] 解绑后冻结归档：可查看、可导出、不可编辑；重新绑定解冻恢复
- [x] 一个空间最多两名成员，双方账号不合并

## 隐私与权限

- [x] 每条记录可设可见范围，默认「仅自己可见」
- [x] 私人内容不会默认展示给另一方，且不可申请查看
- [x] 照片与附件继承所属记录可见范围，不单独设置
- [ ] 服务端逐条校验 `space_id` / `owner_id` / `visibility`，前端状态不作为权限依据（阶段 8 云端接入后完成）

## 数据与同步

- [ ] 本地 Room 仅作缓存与 outbox，云端为权威数据源
- [ ] 同步触发：打开 APP、切回前台、网络恢复、手动同步
- [ ] 先推 outbox 再拉增量，失败保留 outbox 并可重试
- [ ] 冲突：可合并则合并，否则提示用户选择；冲突快照保留 30 天
- [ ] 离线删除优先，共同内容进回收站

- [ ] 彻底删除需双方确认（`purge_requested_by` / `purge_confirmed_by`）
