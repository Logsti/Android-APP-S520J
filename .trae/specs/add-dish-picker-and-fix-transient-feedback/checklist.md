- [x] 页面不再有全局筛选标签行，改为荤菜／素菜／汤／主食每组前置二级分类筛选，默认“全部”
- [x] 荤菜二级分类为猪、牛、羊、鸡、鸭、鹅、鸽子、鹌鹑、火鸡、兔肉、驴肉、鹿肉、牛蛙、田鸡、雪蛤、鱼、虾、螃蟹、贝、其他水产

- [x] 自建库同样按一级／二级分类与四组打标，离线时荤／素／汤／主食都能抽到
- [x] 每组份数限制 0–4 且总数至少 1，四组全为 0 时禁用随机并提示至少选 1 道；降级数据凑不齐时给出说明且不静默改份数
- [x] 每日调用计数落库且跨实例可见，当日剩余低于 20 次时只读池子
- [x] 定时任务只使用当日剩余配额（保留 20 次保底），不与用户点菜抢额度

- [x] 入库只保留菜名、一级分类、二级分类、分组、分类路径、来源、时间，不含步骤、配料、图片或完整响应
- [x] `dishes` 按「菜名＋分类路径」去重，重复菜只更新时间，云端池子上限 10 万道并按最久未出现淘汰
- [x] 入库失败只记受控日志，不影响本次结果展示，也不输出 AppKey
- [x] 实时抽页→云端池子→本机缓存快照→自建库四级降级可用，且每级在界面明确标注
